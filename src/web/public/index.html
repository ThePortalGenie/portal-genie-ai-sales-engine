How to read this file

Last login date is subscriber authentication — when that Portal Genie user last signed in.

Portal visits = visits by the subscriber's clients. They are not subscriber logins. Do not treat those two metrics as the same thing.

Blank is UNKNOWN, not zero. A recorded 0 is a known zero.

Portal Genie usage never changes the Nagging Panda relationship by itself.
